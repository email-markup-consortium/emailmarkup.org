## Attributes

- `high`
- `low`
- `max`
- `min`
- `optimum`
- `value`

## Recommendation

It is highly recommended for an email client to support the `<meter>` element and its attributes.

## Impacts

### Accessibility

Native meter semantics expose a measurement and its range to assistive technology. Preserve a meaningful accessible name and the attributes that describe the value and thresholds.
