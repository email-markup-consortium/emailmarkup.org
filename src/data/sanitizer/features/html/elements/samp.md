## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<samp>` element.

## Impacts

### Accessibility

Preserving sample-output markup retains the distinction between program output and surrounding instructions. Essential meaning should remain clear without monospace styling.
