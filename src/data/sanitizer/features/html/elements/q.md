## Attributes

- `cite`

## Recommendation

It is highly recommended for an email client to support the `<q>` element.

### cite

The `cite` attribute can be retained as source metadata. Retaining the URL should not automatically fetch the cited resource or imply that every URL scheme is supported.

## Impacts

### Accessibility

Preserving quotation markup retains the distinction between quoted words and surrounding prose. Keep quotation punctuation understandable if styling changes.
