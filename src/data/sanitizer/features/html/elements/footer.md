## Attributes

This element has no element-specific attributes.

## Recommendation

This section is under active discussion.

## Impacts

### Accessibility

A footer can expose a content-information landmark depending on its ancestors. Preserve the original nesting so an article footer is not mistaken for the email client’s own footer.
