## Attributes

- `autolocate` - experimental
- `watch` - experimental

## Recommendation

This section is under active discussion.

This element is experimental and is not defined by the HTML Standard. Its handling remains under active discussion.

## Impacts

### Privacy

Location access exposes sensitive recipient information. Any future support would need an explicit permission model appropriate to third-party email content.
