## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<dd>` element.

## Impacts

### Accessibility

Preserve descriptions together with their corresponding `<dt>` terms and parent `<dl>` so assistive technology can interpret the relationships.
