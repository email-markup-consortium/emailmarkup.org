## Attributes

- `align` - deprecated
- `bgcolor` - deprecated
- `char` - deprecated
- `charoff` - deprecated
- `valign` - deprecated

## Recommendation

It is highly recommended for an email client to support the `<tfoot>` element.

### Deprecated attributes

The positive recommendation does not include the deprecated attributes listed above. Their handling is under active discussion.

## Impacts

### Accessibility

Preserving the footer row group retains the structure of summary rows and their relationships with table headers.
