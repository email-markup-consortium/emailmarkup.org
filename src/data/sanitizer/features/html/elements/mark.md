## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<mark>` element.

## Impacts

### Accessibility

Preserving highlights retains the author’s indication of relevant content. Screen readers do not consistently announce highlighting, so essential meaning should also be conveyed in text.
