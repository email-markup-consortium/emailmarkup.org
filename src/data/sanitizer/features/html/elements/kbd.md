## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<kbd>` element.

## Impacts

### Accessibility

Preserving keyboard-input markup retains the distinction between instructions and ordinary prose. Instructions should still make sense when the element’s default styling is unavailable.
