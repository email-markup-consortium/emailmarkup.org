## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<i>` element.

## Impacts

### Accessibility

Preserving the markup retains distinctions such as technical terms and alternate voices. Assistive technology does not consistently announce italic text; language changes should also retain the appropriate `lang` attribute.
