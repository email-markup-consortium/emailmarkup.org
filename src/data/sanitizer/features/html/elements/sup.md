## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<sup>` element.

## Impacts

### Accessibility

Superscripts can carry meaning in exponents, ordinal indicators, and note references. Preserve their relationship to surrounding text and keep note links operable where present.
