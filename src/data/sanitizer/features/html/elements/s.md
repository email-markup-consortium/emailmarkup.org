## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<s>` element.

## Impacts

### Accessibility

Preserving the markup retains the distinction between current text and information that is no longer accurate. Strikethrough is not consistently announced by screen readers, so significant corrections should also be explained in text.
