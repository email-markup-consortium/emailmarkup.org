## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<var>` element.

## Impacts

### Accessibility

Preserving variable markup retains the distinction between identifiers and ordinary prose. Mathematical relationships should not depend on italic styling alone.
