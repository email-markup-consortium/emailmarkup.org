## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<rt>` element.

## Impacts

### Internationalisation

Preserving annotation text and its association with the parent `<ruby>` retains pronunciation and reading guidance for East Asian text.
