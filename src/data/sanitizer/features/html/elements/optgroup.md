## Attributes

- `disabled`
- `label`

## Recommendation

It is highly recommended for an email client to support the `<optgroup>` element and its attributes.

## Impacts

### Accessibility

Labeled option groups help users understand related choices within a select control. Preserve the `label` and the relationship with the parent `<select>`.
