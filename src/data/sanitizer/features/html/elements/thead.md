## Attributes

- `align` - deprecated
- `bgcolor` - deprecated
- `char` - deprecated
- `charoff` - deprecated
- `valign` - deprecated

## Recommendation

It is highly recommended for an email client to support the `<thead>` element.

### Deprecated attributes

The positive recommendation does not include the deprecated attributes listed above. Their handling is under active discussion.

## Impacts

### Accessibility

Preserving the header row group keeps column headings structurally associated with the table’s data.
