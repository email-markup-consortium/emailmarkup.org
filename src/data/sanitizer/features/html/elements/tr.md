## Attributes

- `align` - deprecated
- `bgcolor` - deprecated
- `char` - deprecated
- `charoff` - deprecated
- `valign` - deprecated

## Recommendation

It is highly recommended for an email client to support the `<tr>` element.

### Deprecated attributes

The positive recommendation does not include the deprecated attributes listed above. Their handling is under active discussion.

## Impacts

### Accessibility

Preserving rows retains the relationship between cells and supports meaningful table navigation by assistive technology.
