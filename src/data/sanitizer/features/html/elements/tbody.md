## Attributes

- `align` - deprecated
- `bgcolor` - deprecated
- `char` - deprecated
- `charoff` - deprecated
- `valign` - deprecated

## Recommendation

It is highly recommended for an email client to support the `<tbody>` element.

### Deprecated attributes

The positive recommendation does not include the deprecated attributes listed above. Their handling is under active discussion.

## Impacts

### Accessibility

Preserving row groups keeps table structure and row-group header relationships intact. Keep the original rows and cells inside their table.
