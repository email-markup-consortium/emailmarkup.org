## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<b>` element.

## Impacts

### Accessibility

Preserving the markup retains the author’s distinction between text that draws attention and text with strong importance. Authors should use `<strong>` when importance is intended; a bold appearance alone does not communicate that meaning to all users.
