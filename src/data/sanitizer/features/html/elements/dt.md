## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<dt>` element.

## Impacts

### Accessibility

Keep terms associated with their `<dd>` descriptions within the same `<dl>` so the relationships survive sanitization.
