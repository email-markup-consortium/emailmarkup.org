## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<cite>` element.

## Impacts

### Accessibility

Preserving citation markup retains the distinction between a work’s title and surrounding prose. Assistive technology does not consistently announce this distinction, so meaning should not depend on italic styling alone.
