## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<small>` element.

## Impacts

### Accessibility

Preserving the markup retains the author’s identification of side comments or small print. The email client should allow text resizing so this content remains readable.
