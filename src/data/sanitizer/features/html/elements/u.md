## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<u>` element.

## Impacts

### Accessibility

Preserving annotation markup retains distinctions such as spelling annotations. Underlining alone is not consistently announced by assistive technology and can be confused with a link, so essential meaning needs accompanying text.
