## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<search>` element.

## Impacts

### Accessibility

Native search landmark semantics help assistive technology users find search or filtering controls. Preserve an accessible name when multiple search regions need to be distinguished.
