## Attributes

This element has no element-specific attributes.

## Recommendation

It is highly recommended for an email client to support the `<rp>` element.

## Impacts

### Progressive enhancement

Preserving ruby fallback parentheses keeps annotations distinguishable from base text in clients that do not render ruby layout.
